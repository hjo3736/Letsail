# Let'sail 캐릭터 동작 목록 (애니메이션 제작용)

기준일: 2026-11-12. 게임에 지금 들어 있는 동작과, 기획 문서에 있지만 아직 기능이 없는 동작을 모두 적었다.
대상 파일: `Assets/_Project/Art/Models/Player/player.fbx` (Generic 리그, 지금 클립 95개).

## 표기

**키 방식**
| 표기 | 뜻 |
|---|---|
| 짧게 | 한 번 눌렀다 뗀다 |
| 길게 N초 | N초 동안 누르고 있어야 실행된다. 중간에 떼면 취소된다 |
| 누르고 있기 | 누르고 있는 동안 계속된다 (달리기, 웅크리기) |
| 자리 | E 짧게로 자리를 잡고, 다시 E 짧게로 일어난다. 자리에 있는 동안 아래 조작 키를 쓴다 |

**클립 상태**: ✅ 있음·사용 중 / 🟡 있음·아직 안 씀 / ❌ 없음 (만들어야 함)

**공통 규칙**
- 캐릭터 키 1.15m. 앞쪽은 +Z (Blender에서 -Y 앞, Forward -Z / Up Y로 내보내기).
- 제자리 애니메이션 (Root Motion 안 씀). 위치 이동은 코드가 한다. 루트(발밑)는 원점에 둔다.
- 반복 동작(loop)은 첫 프레임과 마지막 프레임이 이어져야 한다.
- 들어가기·나오기 같은 한 번 재생하는 동작은 0.3~1.0초 정도로 짧게. 나오기 끝 포즈는 Idle과 같게.
- 클립 이름은 `분류_동작` (예: `Helm_Idle`). 지금 있는 이름은 바꾸지 않는다.

## 2. 배 위 상호작용 (지금 기능 있음, 애니메이션은 없음)

지금은 자리에 붙거나 순간이동만 하고, 애니메이션은 `Idle` 이 나온다.

### 2-1. 키 (조타)
위치: 후미 선루 위, 키 바퀴(지름 1.3m, 바퀴 중심 높이 약 0.95m) 뒤 0.4m에 서서 바퀴를 마주 본다.

| 동작 | 키 | 방식 | 클립 | 상태 | 메모 |
|---|---|---|---|---|---|
| 키 잡기 | E | 짧게 | `Helm_Grab` | 🟡 | 두 손으로 바퀴 손잡이를 잡는다 |
| 키 잡고 서 있기 | - | 자리 | `Helm_Idle` | 🟡 | loop |
| 키 왼쪽으로 돌리기 | A | 누르고 있기 | `Helm_TurnLeft` | 🟡 | loop. 바퀴는 코드가 돌린다 (끝에서 끝까지 한쪽 540도) |
| 키 오른쪽으로 돌리기 | D | 누르고 있기 | `Helm_TurnRight` | 🟡 | loop |
| 키 놓기 | E | 짧게 | `Helm_Release` | 🟡 | |
