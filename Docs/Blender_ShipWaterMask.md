# 배 안쪽 물 가림 메시 (Hull_WaterMask) 만들기

## 왜 필요한가

바다는 수면 하나를 통째로 그리기 때문에, 배 안(선창)에도 수면이 그대로 보인다.
지금 배는 수면이 배 기준 높이 약 0m에 오는데, 선창 바닥은 -0.78m, 아래 칸 침대는 -0.22m라 물에 잠긴 것처럼 보인다.

Unity에서는 **배 안쪽 공간 모양의 닫힌 메시**를 하나 받아서, 바다 셰이더가 그 공간 안에 들어오는 수면을 그리지 않게 한다.
이 메시는 화면에 보이지 않고, 충돌체도 달지 않는다. 그래서 모양만 정확하면 된다.

## 만들 것

| 항목 | 내용 |
|---|---|
| 오브젝트 이름 | `Hull_WaterMask` (정확히 이 이름) |
| 위치 | 다른 부품처럼 배 최상위에 둔다 (`Hull_Core` 와 같은 단계). 원점·회전·크기는 배와 같게 (Apply Transform) |
| 모양 | **선체 바깥면을 따라 감싼 공간**을, **갑판 높이(배 기준 2.08m)에서 평평하게 자른 것** |
| 닫힘 | 구멍 없이 완전히 닫힌 메시 (Non-Manifold 없음) |
| 법선 | 모두 바깥쪽 (Recalculate Outside) |
| 크기 | 선체 바깥면과 같거나 1~2cm 안쪽. **바깥으로 커지면 안 된다** (배 옆 바다가 같이 사라짐) |
| 폴리곤 | 적을수록 좋다. 500 삼각형 안팎이면 충분 |
| 머티리얼 | 아무거나 하나 (예: `M_WaterMask`). Unity에서 화면에는 그리지 않는다 |

### 범위
- 아래: 선체 맨 밑(용골)까지 전부.
- 위: 갑판 높이 2.08m에서 평평한 뚜껑으로 닫는다. 파도가 아무리 높아도 갑판 위로 넘치지 않는 한 이 높이면 충분하다.
- 해치(선창 입구) 구멍은 막아서 닫는다. 뚜껑이 해치를 덮어도 하늘은 그대로 보인다 (이 메시는 수면만 가린다).
- 선루(Castle), 난간, 돛대처럼 갑판 위에 있는 것은 넣지 않는다.
- 뱃머리 끝, 고물(뒤쪽) 끝까지 선체 모양을 따라야 한다. 상자 모양으로 대충 만들면 끝부분에서 물이 보이거나, 반대로 배 바깥 물이 잘린다.

## 만드는 순서 (예시)

1. `Hull_Core` 를 복제(Shift+D)하고 이름을 `Hull_WaterMask` 로 바꾼다.
2. 편집 모드에서 안쪽 면, 난간, 장식, 갑판 위 부분을 지우고 **바깥 껍데기만** 남긴다.
3. Bisect 로 배 기준 높이 2.08m(Blender에서는 Z = 2.08)를 자른다. Clear Outer(위쪽 버림)와 Fill 을 켜서 뚜껑을 만든다.
4. 남은 구멍을 F 로 메운다. Select > All by Trait > Non Manifold 로 아무것도 선택되지 않을 때까지 정리한다.
5. 면이 많으면 Decimate(Collapse)로 줄인다. 모양이 바깥면 밖으로 튀어나오지 않는지 확인한다.
6. 원하면 Alt+S 로 -0.01 ~ -0.02 만큼 안쪽으로 줄인다.
7. 법선을 바깥으로 맞춘다 (Shift+N).
8. 다른 부품과 같은 설정으로 `playership_001.fbx` 에 덮어써 내보낸다 (같은 경로, 같은 이름, Forward -Z, Up Y, Apply Transform).

## 확인할 것

- 내보낸 뒤 다른 오브젝트 이름이 바뀌지 않았는지 (Unity 프리팹의 상호작용 연결이 이름으로 붙어 있다).
- `Hull_WaterMask` 하나만 새로 생겼는지.

## 나중에: 선창 침수

배에 구멍이 나서 선창에 물이 차는 것은 이 가림 메시와 별개로, 선창 안에 따로 놓는 물 면(`M_FloodWater` 머티리얼)으로 표현한다.
그 물 면은 선창 바닥 모양을 덮는 평평한 판 하나면 되고, Unity에서 수위를 올린다.
필요하면 `Hold_FloodWater` 라는 이름으로 같이 만들어 두면 된다 (선창 바닥 전체를 덮는 판, 높이는 바닥과 같게).
